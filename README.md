Sales Performance Analysis Dashboard | Excel

1. Project Overview

This project focuses on analysing sales performance using Microsoft Excel. The goal is to understand sales trends, compare product performance, and evaluate regional sales through an interactive dashboard.

2. Project Objectives

- Analyse overall sales performance.
- Compare sales across different products.
- Evaluate sales performance across regions.
- Identify sales trends.
- Present business insights through an interactive dashboard.

3. Tools Used

- Microsoft Excel

4. Dataset Description

The sales dataset contains the following fields:

Column| Description
Date| Date of sale
Product| Product name
Region| Sales region
Sales| Sales amount

5. Skills Demonstrated

- Data organization
- Excel formulas
- Sales analysis
- KPI calculations
- Data visualization
- Dashboard development

6. Project Files

- Sales Performance Analysis - Excel.pdf – Project documentation.

7. Key Learning Outcomes

This project helped develop practical skills in Microsoft Excel, sales data analysis, business reporting, and dashboard creation.

8. Conclusion

This project demonstrates the use of Microsoft Excel to analyse sales data and communicate business performance through visual reporting.
